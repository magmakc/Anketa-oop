# Обработчик анкет на ООП

## Возможности

- Чтение анкет из файла `anketa.txt`.
- Поддержка двух типов анкет: **студент** (`s`) и **преподаватель** (`t`).
- Проверка ФИО, почты, телефона и дополнительного поля (группа/кафедра).
- Обработка ошибок через собственное исключение `AnketaError`.
- Вывод таблицы принятых анкет с маскировкой телефона.
- Статистика по ролям и группам.
- Сохранение результатов в `ok.txt` и `errors.txt`.
- Корректная работа при отсутствии входного файла (без traceback).

## Требования

- Python 3.10 или новее.
- Стандартная библиотека (без внешних зависимостей).
